> CLAUDE.md에 한국어 규칙을 적어 둔 뒤에도 영어 답이 나왔던 경험과 한국어 응답을 위해 시도한 설정을 정리했습니다

<!--more-->

## 개요

요즘 Claude 답에 영어가 자주 섞여 나왔습니다. 저만 그런 줄 알았는데 같이 스터디하는 분들도 비슷한 경험을 했다고 해서 궁금해졌습니다

예전에도 간혹 답변이 다른 언어로 나와서 `CLAUDE.md`에 "모든 답은 한국어로"라고 적어 두고 쓰고 있었습니다. 그런데도 영어가 계속 나오니 이유가 궁금했습니다. Claude에게 직접 물어보고 한국어로 답하게 할 방법을 찾아봤습니다

## 영어가 섞여 나왔던 상황

처음에는 pstack 같은 영어 스킬을 쓸 때만 그런 줄 알았습니다. 그런데 스킬 없이 Paper MCP로 대시보드 시안 세 개를 그리게 했을 때도 같은 일이 생겼습니다. 작업 중에 보낸 진행 문장부터 영어였습니다

```text
Sidebar first.
Main column: header and search bar.
Now the B option: I'm reusing the B6 summary cards.
Last, the C option: a table-based summary.
```

최종 답도 영어로 왔습니다. 한국어로 다시 달라고 했는데도 영어로 답했습니다

`CLAUDE.md`에는 "짧은 확인 답까지 전부 한국어"라고 적혀 있었습니다. 이 규칙이 있는데도 왜 영어로 답했는지, Claude가 지시와 도구 결과를 어떻게 받아들이는지 알고 싶었습니다

## 왜 그런지 물어봤을 때 들은 설명

Claude에게 물어보고 들은 설명을 정리해 봤습니다. Claude도 이번 답변이 왜 영어로 나왔는지 내부 과정을 직접 확인한 건 아니어서, 아래 내용은 가능한 이유에 대한 설명입니다

Claude는 답을 만들 때 `CLAUDE.md`의 규칙뿐 아니라 대화와 도구 결과도 함께 참고한다고 했습니다. "한국어로 써라"라는 규칙이 있어도 답이 항상 한국어로 나오지는 않는다는 설명이었습니다

Claude가 설명한 대화의 흐름은 이랬습니다

1) 시스템 프롬프트 (Claude Code 기본 지시와 `language` 설정)
2) 첫 메시지에 붙는 안내 (`CLAUDE.md`와 메모리)
3) 대화
4) 도구 호출과 결과 (MCP 안내서와 Paper 결과)
5) 그다음에 쓰는 문장

이 목록은 지시의 우선순위가 아니라, 대화에 들어오는 내용을 대략 나눈 것입니다. `CLAUDE.md`의 규칙은 앞쪽에 있고 Paper 도구 결과는 답을 쓰기 직전에 들어왔다는 차이가 있었습니다

이번 작업에서는 Paper 사용 안내와 도구 결과가 영어로 길게 이어졌습니다. Claude는 그 영어 문맥이 답변 언어에 영향을 줬을 수 있다고 설명했습니다. 한국어로 다시 달라고 한 뒤에도 영어가 나온 이유는 이 설명만으로 알 수 없습니다. 그래도 당시 대화에서 살펴볼 만한 부분이라고 느꼈습니다

## 업데이트 때문이었을까

요즘 들어 잦아졌다는 느낌이 있어서 업데이트 탓인지도 찾아봤습니다. 제가 확인한 Claude Code 변경 기록에서는 응답 언어가 영어로 바뀌었다는 내용을 찾지 못했습니다

대신 `/context`로 당시 맥락에 뭐가 얼마나 들어 있는지 봤습니다. 한국어 규칙이 있는 `CLAUDE.md`는 1.5k 토큰이었고, 영어로 된 안내는 이렇게 표시됐습니다

1) Claude Code 기본 도구 설명 16.4k
2) 스킬 목록 9.9k (200개)
3) MCP 서버 안내 5.4k
4) 시스템 프롬프트 3.5k

표시된 수치를 합치면 35k 토큰이 넘습니다. 다만 이 수치만으로 영어 답변의 원인을 알 수는 없습니다

스킬 목록에는 제가 직접 깐 것 외에 Claude Code 기본 스킬과 claude.ai 계정에서 연동된 스킬도 섞여 있었습니다. Figma나 Notion 같은 커넥터도 계정에 연결돼 있었습니다

영어로 된 안내가 예전보다 늘었는지, 그것이 답변 언어에 영향을 줬는지는 확인하지 못했습니다. 모델이나 업데이트의 영향도 지금으로서는 알 수 없습니다

## 규칙을 더 적으면 달라질까

처음에는 `CLAUDE.md`의 문장을 더 강하게 써야 하나 싶었습니다. 그런데 이미 "짧은 확인 답까지 전부 한국어"라고 적어 둔 상태였습니다

같은 파일에 비슷한 말을 더 넣기 전에 Claude Code에서 언어를 정하는 다른 방법을 찾아봤습니다

## `language` 설정부터 적용

Claude Code 변경 기록에서 응답 언어를 정하는 `language` 설정을 찾았습니다

```text
Added `language` setting to configure Claude's response language (e.g., language: "japanese")
```

제 `~/.claude/settings.json`에는 최상위 `language` 설정이 없었습니다. `"language": "auto"`가 하나 있었지만 플러그인 전용 옵션이라, 최상위에 다음 한 줄을 넣었습니다

```json
{
  "language": "korean",
  "env": {
    ...
  }
}
```

설정을 넣은 뒤에는 시스템 프롬프트에서 "Always respond in korean"으로 시작하는 지시를 확인했습니다. `CLAUDE.md`에만 적어 두는 것과 결과가 얼마나 다른지는 아직 모릅니다. 며칠 써 보면서 Paper MCP 작업에서도 영어가 섞이는지 확인하려고 합니다

## 그래도 영어가 나오면 `PostToolUse` 훅

`language` 설정을 적용한 뒤에도 MCP 작업에서 영어가 나오면 `PostToolUse` 훅을 시도해 볼 생각입니다. 도구 결과 뒤에 한국어 규칙을 다시 보여 주는 방법입니다

생각한 설정은 `PostToolUse` 훅에서 MCP 도구(`mcp__.*`)만 골라 한국어 안내를 추가하는 것입니다. 아래는 아직 적용하거나 검증하지 않은 예시입니다

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "mcp__.*",
        "hooks": [
          {
            "type": "command",
            "command": "echo '{\"hookSpecificOutput\":{\"hookEventName\":\"PostToolUse\",\"additionalContext\":\"사용자에게 보이는 문장(중간 진행 문장 포함)은 한국어로 쓴다.\"}}'"
          }
        ]
      }
    ]
  }
}
```

이 방법이 중간 진행 문장까지 바꾸는지는 적용해 봐야 알 수 있습니다. 도구를 부를 때마다 안내가 추가되는 만큼 사용량도 늘어날 수 있습니다

답을 보낸 뒤 영어가 섞였는지 검사하는 `Stop` 훅도 생각해 봤습니다. 하지만 답을 다 쓴 뒤에 검사하므로 중간 진행 문장은 잡지 못하고, 코드나 파일 이름이 영어인 경우에도 잘못 반응할 수 있어 제외했습니다

어느 방법이 도움이 됐는지 구분하려고 우선 `language` 설정만 적용했습니다

## Codex는 어떨까

Codex에도 Claude Code의 `language` 같은 응답 언어 설정이 있는지 찾아봤습니다. 당시 쓰던 `codex-cli 0.159.3`의 `config.toml`과 `codex --help`에서는 찾지 못했습니다

다만 문서를 다 본 건 아니라서 아예 없다고 하기는 어려울 것 같습니다

지금은 `~/.codex/AGENTS.md`에 한국어 규칙을 적어 두고 있습니다. Codex에서 같은 문제가 생기는지는 따로 확인하지 않았습니다

Codex에도 `hooks.json`이 있어서 비슷한 훅은 걸 수 있지만 Claude Code처럼 도구 결과 뒤에 문장을 붙여 모델에게 보여 주는지는 아직 확인하지 못했습니다

영어로 된 도구 안내와 결과가 영향을 줬을 가능성은 있지만, 이번 사례만으로 원인을 단정할 수는 없습니다. 우선 Claude Code의 `language` 설정을 적용했습니다. 같은 작업에서 효과가 있는지 며칠 더 써 보고, 그래도 영어가 나오면 `PostToolUse` 훅을 검토해 보려고 합니다
